# WanderLust
WanderLust is a full-stack travel listing web application built using Node.js, Express.js, EJS, and MongoDB. Explore and book unique stays like villas, tree houses, and boat houses across the world.

 # Check out WanderLust
 https://wanderlust-0a54.onrender.com/listings

 # 🛠️Technologies Used

1.Frontend: EJS, HTML, CSS, JavaScript

2.Backend: Node.js, Express.js

3.Database: MongoDB

4.Other Libraries/Tools:

    method-override (for PUT and DELETE requests)

    dotenv (for environment variables)

    mongoose (MongoDB object modeling)

    ejs-mate (EJS layouts & partials)

# 📌Features

1.Browse trending destinations and filtered categories (Rooms, Beaches, Mountains, Castles, etc.)

2.View individual listings with details and pricing

3.User authentication (Sign up / Login / Logout)

4.Host dashboard to manage listings

5.Option to display total cost after taxes

6.Responsive design for desktop and mobile
